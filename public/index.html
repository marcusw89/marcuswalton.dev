How this site runs

This site is plain HTML, CSS and JavaScript with no build step, served from Cloudflare's edge by a small Worker. The Worker redirects www and the .co.uk domains to marcuswalton.dev and adds security headers (a strict Content-Security-Policy, HSTS, nosniff) to every response. Pushing to GitHub deploys it automatically, and Cloudflare's bot protection filters automated traffic before it reaches the site. Fonts are self-hosted and nothing on the site sets cookies.

The Linux Command Vault takes the opposite approach, with a generator and a Quartz build: see how it's built.

About me

I'm a system administrator at heart, working as a technical support engineer at iomart since 2021. Most of my day is working out why a Linux server is misbehaving and fixing it so it stays fixed, and the bigger projects, like moving Memset's VPS platform onto OnApp, are the parts I enjoy most.

Before that I spent five years as a freelance IT consultant, designing secure networks, running VPNs and firewalls, and building backup and disaster recovery plans for clients. I care about uptime, security and automating the repetitive parts of the job.

Outside work I run a home lab, where I test everything that goes into my Linux Command Vault, from Proxmox clusters and Ceph to mail servers and firewalls.
