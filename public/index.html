How this site runs

This site is plain HTML, CSS and JavaScript with no build step, served from Cloudflare's edge by a small Worker. The Worker redirects www to the main domain and adds security headers (a strict Content-Security-Policy, HSTS, nosniff) to every response. Pushing to GitHub deploys it automatically, and Cloudflare's bot protection filters automated traffic before it reaches the site. Fonts are self-hosted and nothing on the site sets cookies.

  • Cloudflare Workers
  • Bot protection
  • CSP & HSTS
  • No build step
